A Full-Stack Developer with 3+ years of professional experience designing and building scalable, production-grade web and mobile applications. Strong expertise in TypeScript, React, Next.js, React Native, Node.js, Express.js, Nest.js, MongoDB, and PostgreSQL, along with modern state-management solutions such as Redux Toolkit, Zustand, and TanStack Query. Hands-on experience building AI-powered features — LLM workflows, AI agents, and Claude-based solutions — and integrating them into production products.

Currently working as a **Full-Stack Developer** at **Gcontent**, where I design and build backend systems from architecture through deployment, ship AI-powered features using the Claude API, and develop end-to-end across web and mobile applications using React, React Native, and Expo. Previously, at **Standard Insights**, I built a GenAI chatbot and RAG pipeline (Anthropic API + MongoDB Atlas Vector Search) for a consumer research platform used by brands including PepsiCo, Unilever, Cartier, and Singha, and shipped production features, refactored legacy systems, and optimized backend performance.

Hands-on experience with MongoDB, PostgreSQL, Redis, Prisma, Mongoose, TypeORM, Docker, and basic AWS services. Successfully delivered multiple real-world projects including inventory management systems, university registration platforms, and role-based web applications, featuring authentication, authorization, approval workflows, and data visualization.

A detail-oriented and growth-driven engineer with a strong passion for clean architecture, AI-powered products, and continuous learning. Actively building and shipping full-stack and mobile products end-to-end, from Figma to production.
